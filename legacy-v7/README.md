# Optical Bench

一个无需服务器、可在本地浏览器运行的二维几何光线追迹与光路设计器。

## 运行

直接双击 `dist/index.html` 即可使用。浏览器会在本机保存设计，也可以通过 JSON 导入和导出。

## 添加自定义器件

编辑 `dist/components.js`，在 `window.OPTICAL_COMPONENTS` 中复制现有条目并修改：

- `name`：显示名称
- `icon`：画布图标
- `defaults`：器件参数
- `transform(beam, params)`：光束经过器件后的波长、功率和偏振变换

`beam` 中还包含高斯光束复 `q` 参数、`m2`、初始脉宽与累计 `gdd`。器件可通过 `rayBehavior` 指定 `source`、`reflect`、`split` 或 `stop`。

## 几何规则

- 激光器的朝向决定发射方向。
- 反射镜的朝向代表镜面切线方向，光线按照反射定律改变方向。
- 分束镜产生反射与透射两条光束。
- 波片、偏振片、透镜与延时台被命中后沿原方向继续传播。
- 样品和探测器作为终点停止光线。

## V3 精确模型

- 反射镜与分束镜按有限长度线段求交，`aperture` 决定有效尺寸。
- 透射器件可设置有效口径、厚度与折射率，分别累计几何长度和 `OPL = ΣnL`。
- 光束靠近器件口径边缘时会显示切光警告。
- 选中器件后可拖动橙色手柄旋转；默认吸附 5°，按住 Shift 为 1°，Alt 为连续旋转。
- 半波片、四分之一波片和偏振片使用 Jones 向量传播，并显示线偏振、圆偏振或椭圆偏振状态。

## V4 高斯光束与超快脉冲

- 激光源可设置束腰半径、M²、初始脉宽和初始 GDD。
- 自由空间传播使用复 q 参数；薄透镜使用 ABCD 矩阵更新光斑。
- 画布用半透明包络显示每段光束半径（为便于观察按 2.5 倍绘制）。
- 光束碰到器件时按局部可用口径估算透过比例，并提示截断风险。
- 介质器件可输入 GDD，软件按高斯脉冲近似估算展宽后的 FWHM。
- 点击样品可比较到达时间、光斑、脉宽、入射夹角及共轴高斯空间重合估算。

当前群延迟仍以器件填写的折射率近似群折射率；空间重合值假设两束光在样品中心重合，仅比较光斑尺寸。

## V5 实验搭建工具

- 直接拖动平台可整体移动；按住 Shift 在平台上拖动可框选器件，平台外空白处可直接框选；支持 Shift 增选、整组移动和 Delete 批量删除。
- 透镜后的光束使用复 q 参数计算实际束腰位置，并在画布标出距离和束腰半径。
- 延时台改为折返镜组：返回光与入射光平行反向，并具有可调横向间距；平台移动量 `x` 产生 `2x` 的光程变化。
- 可直接输入目标延时（ps），自动换算延时台移动量；空气中移动 1 mm 对应约 6.671 ps。
- 新增光阑、ND 滤光片和长通/短通波长滤光片。
- 激光器可输入重复频率；样品节点估算单脉冲能量、峰值功率和中心峰值 fluence。

峰值功率和 fluence 使用时域、空间均为高斯分布的近似。滤光片目前采用理想截止波长与常数通带/阻带透过率，不代替厂商实测光谱。

## V6 光谱器件、探测与诊断

- 新增二向色镜，可按截止波长选择短波或长波反射，另一波段透射。
- 新增 BBO 倍频/混频晶体：单束光可生成残余基频与二倍频；两束光同时命中且到达时间差小于互相关脉宽时，还会沿两束入射方向之间生成和频光，满足 `1/λout = 1/λ1 + 1/λ2`。
- 探测器可设置响应波段、响应度、跨阻增益和饱和功率，估算光电流及输出电压。
- 每个器件具有光轴高度；俯视图相交但高度不一致时，光束不会命中并产生诊断提示。
- 光阑会报告光束偏心量；探测器会报告饱和和波段不匹配。
- 延时台可设置扫描起点、终点和步长，并显示 50 fs + 50 fs 的参考互相关曲线。

BBO 当前采用用户填写的总转换效率，不求解完整耦合波方程；探测器计算采用线性响应近似。

## V7 同步、诊断与编辑历史

- 新增 60 步撤销/重做，支持工具栏按钮以及 `Ctrl+Z`、`Ctrl+Y` / `Ctrl+Shift+Z`。
- BBO 双束混频会同时检查脉冲时间重合、入射夹角和偏振条件；诊断区显示差值、输出波长和预计相对信号。
- 延时台扫描曲线改为读取当前实际到达 BBO 的两路光，自动给出零延时位置与 FWHM，并可导出 CSV。
- 新增“双光阑对准”模式：依次点击近场、远场光阑，估算横向偏移和角度误差，并给出调整顺序。
- BBO 可设置目标入射夹角、夹角容差、偏振模式（`any` / `parallel` / `crossed`）与偏振容差。

工作区使用大尺寸画布，并提供横向、纵向滚动条；画布尺寸会随光学平台范围自动扩展。按住 Ctrl 并用鼠标左键拖动，可从平台、器件或光束上的任意位置平移整个画布。
