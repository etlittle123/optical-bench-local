# Optical Bench 3D

一个交互式三维光路搭建与仿真平台，支持按厂商和型号选择光学器件、自定义材料的透射与反射行为，并直观展示光束传播路径和偏振状态。集成预设动作、实验数据导入、曲线绘制与实验日志导出，方便光路设计、教学演示和实验记录。

An interactive 3D optical bench simulator for building and exploring optical setups. Select components by manufacturer and model, configure material transmission and reflection, visualize beam paths and polarization, and organize experiments with preset actions, imported data, plots, and exportable reports.

## 快速开始

下载项目后，用浏览器打开 [`dist/index.html`](dist/index.html) 即可使用，无需安装依赖或执行构建。

1. 在左侧器件库中点击器件类型，选择已收录的厂商型号，或添加通用器件。
2. 在三维平台上拖动器件，在右侧调整坐标、姿态和光学参数。
3. 查看光束传播路径与偏振状态，使用路径测量和双光阑对准工具辅助搭建。
4. 打开“实验记录”填写实验信息，或通过“数据表与绘图”导入数据并绘制曲线。
5. 使用“保存”保存到当前浏览器，或“导出 JSON”备份和分享设计。

浏览器保存与当前浏览器环境关联；跨设备使用时，请导出 JSON，并在另一台设备上导入。

## 主要功能

- **三维光路搭建**：调整平台孔距与尺寸，设置器件位置、Yaw、Pitch 和 Roll，切换立体、俯视、正视与侧视视角。
- **统一器件库**：按器件类型选择厂商和型号，查看已收录规格与参数来源；支持导入厂商器材库及自定义器件模组。
- **材料设置**：为材料命名，选择透射、反射或都有，并调整透过率、反射率、厚度、折射率及群折射率。
- **光路与偏振可视化**：显示三维光线、波长、偏振状态及器件名称；光束宽度与亮度随相对功率变化，分束后的强弱一眼可见。支持多光源、分束、透镜、延时台和 BBO 晶体等模型。
- **预设动作**：录制和编辑器件位移、旋转扫描及联动动作，支持流程运行、暂停和重置。
- **数据分析**：导入 TXT、CSV、TSV 数据，编辑工作表、配置列映射、绘制曲线和极坐标图，并进行拟合。
- **实验工作簿**：使用多个 Sheet 管理不同实验，各自保存光路、数据与动作。
- **实验导出**：导出 HTML 日志、实验归档 ZIP，或将全部实验合并为一篇可导入 Notion 的笔记。

厂商库当前按提供的两份报价单、发票和订单价格表收录 **39 个光学器件型号**：LBTEK 11 个、Thorlabs 11 个、Edmund Optics 17 个。包括反射镜、凸透镜、偏振片、半波片、四分之一波片、偏振分束棱镜、沃拉斯顿棱镜、波长滤光片、ND 滤光片、BBO 晶体、光阑和斩波器。重复型号合并，镜架、支杆、底座、位移台、电源及线缆等不纳入。

每个条目保留清单页码或表格位置，并区分已核实参数与通用模拟默认值。连续可变 ND 可修改 OD；10 片装反射镜每次放置一片。PBS 和沃拉斯顿棱镜按偏振分束，斩波器仅模拟占空比对应的时间平均功率。

这是所提供文件的光学器件目录，**不是厂商全量目录、库存管理或精确实测模型**。详细型号、范围及近似说明见 [`catalog/README.md`](catalog/README.md)。此前的公开目录源数据保留供参考，默认不加载；旧设计中的器件和规格快照仍可使用。

## 常用操作

| 操作 | 鼠标或快捷键 |
| --- | --- |
| 选择、移动器件 | 左键点击、拖动 |
| 旋转视角 | Alt + 左键拖动，或启用“旋转视角” |
| 平移画面 | Ctrl + 左键拖动，或中键拖动 |
| 缩放 | 鼠标滚轮 |
| 多选 | Shift + 点击 |
| 切换立体 / 俯视 / 正视 / 侧视 | `1` / `2` / `3` / `4` |
| 适应画面 | `F` |
| 旋转器件 5° | `R` |
| 删除选中器件 | `Delete` / `Backspace` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` 或 `Ctrl+Shift+Z` |
| 保存 | `Ctrl+S` |
| 测量路径 | `M` |
| 双光阑对准 | `A` |
| 开关自动追迹 | `B` |
| 取消当前工具或拖动 | `Esc` |

`R` 对偏振片、半波片及其他普通器件增加 **Yaw**；对四分之一波片增加 **Roll**。偏振片的透光轴和波片的快轴仍通过右侧 **Roll** 参数设置。

## 画面与标签

模拟器采用柔和的浅紫灰背景、立体器件、阴影与光束辉光。材料和旧版样品显示自定义名称；其他器件显示类型名称。标签自动避让器件、光线和其他标签，长名称会换行。

HTML、Notion 和归档中的光路图使用独立的白底示意风格，隐藏平台、支架和编辑辅助信息，并自动裁切空白边缘。平面光路采用俯视图；存在明显高度差时保留空间视角。导出不改变编辑器的视角与光学参数。

## 实验日志

选中 PBS、偏振片或半波片，在右侧点击 **设置极值角度**；也可从“实验数据与日志 → PBS 反射端极值角度”打开。选择对应的激光器、偏振片、半波片和 PBS，填写三项：偏振片固定角度、半波片使 PBS 反射光最强的角度、半波片使反射光最弱的角度。无需填写功率，也不需要扫描。

同一套器件可以保存多个偏振片固定角度；相同器件和固定角度再次保存会更新该条记录，也可选择已有记录编辑或删除。角度按用户输入的实验刻度保存；模拟中的绕光轴转角是 Roll。保存后，模拟按这两个极值校准该半波片的输出偏振，使后续 PBS 的分光满足：Roll 等于“反射最弱”角度时反射为 0，等于“反射最强”角度时为 100%，中间按 sin² 过渡；在记录对应的偏振片设置下，两角度相差 45° 时与理想半波片一致，不相等时按记录拉伸相位。同一半波片保存了多个偏振片角度时，按光路中最后一个偏振片的 Roll 选择最接近的记录（不插值）。

校准只改变半波片到 PBS 的分光比例，不移动器件，也不修改 Roll；偏振片、半波片和 PBS 的透过率与反射率仍照常计入。若半波片与 PBS 之间还有改变偏振方向的器件（如反射镜、四分之一波片），记录的角度关系不再严格成立。记录角度是用户提供的实验刻度，不是自动测量或完整标定曲线。LNO、ND 不参与此项记录。

记录按实验 Sheet 分开保存，随设计 JSON 恢复，并进入 HTML、实验归档和 Notion 笔记的第 4 部分。保存后请使用顶部“保存”下载设计 JSON。

导出的 HTML 和 Notion 日志保留以下四部分：

1. 实验目的与设置
2. 当前模拟光路
3. 预设动作
4. 导入数据与曲线

“全部实验 → 一篇 Notion 笔记”生成用于导入 Notion 的 ZIP 文件。HTML 日志可在浏览器中查看和打印。完整设计与原始数据可通过实验归档另行保存。

## 模拟范围

项目采用简化光学模型，适合光路规划、教学演示和实验记录。透镜采用近轴近似，材料透射采用近法线等效薄片模型，材料反射采用理想镜面模型；BBO 支持近法线、低转换效率条件下的 Type-I 倍频与混频近似。具体约定见 [`dist/bbo-notes.txt`](dist/bbo-notes.txt)。

预设动作在模拟器内执行，不控制真实实验硬件。厂商规格、默认参数和模拟结果应与实际器件及实验条件分别核对。

旧存档中的“样品”保留原有行为以兼容历史设计，新添加的样品与透射材料统一使用“材料”入口。材料选择“都有”时，若透过率与反射率之和超过 100%，计算会按比例归一化。

## 开发与验证

使用 HTML、CSS、JavaScript 和 Canvas 实现。修改 `dist/` 中的文件后，刷新页面即可查看效果。

运行自动检查需要安装 Node.js。在项目根目录的 PowerShell 中执行：

```powershell
Get-ChildItem tests -Filter '*.cjs' | ForEach-Object {
    node $_.FullName
    if ($LASTEXITCODE -ne 0) { throw "Failed: $($_.Name)" }
}
```

测试覆盖三维追迹、偏振、材料分光、厂商目录、动作扫描、数据处理与日志导出。交互检查使用 DOM 适配器，不替代真实浏览器中的布局和鼠标操作验证。
