## 使用与模拟边界

在左侧点击器件类型，再选择厂商、型号。详情显示规格、清单来源及参数依据。添加后在右侧展开“高级模拟参数”修改数值。导出的设计保留完整规格快照；导出的实验笔记继续使用器件类型辅助标签。

- **PBS 49-871**：理想透 P、反 S；默认 Yaw 135° 表示内部分束面法线。未模拟立方体入口折射、有限消光比和内部光程。[官网规格](https://www.edmundoptics.com/p/20mm-nir-polarizing-cube-beamsplitter/10343/)
- **68-823**：α-BBO 沃拉斯顿棱镜，产生两束正交偏振光，与 β-BBO 倍频晶体区分。采用近法线对称分束；初始夹角取官网 800 nm 时的 16°，偏离参考波长提示，夹角可手动修改。未自动模拟夹角色散。[官网规格](https://www.edmundoptics.com/p/a-bbo-wollaston-polarizer/23435/)
- **MC2000B**：只按占空比计算时间平均功率；初始 50% 是模拟设定，不代表刀片规格。未实现转速控制和逐脉冲遮挡。
- **63-048**：OD 可在 0.04–4.0 范围内设置；未模拟梯度膜的空间分布，移动器件不会自动改变 OD。超出范围会提示。[官网规格](https://www.edmundoptics.com/p/od-004-40-762-x-254mm-continuously-variable-nd-filter/17667/)
- **DP12 / DP20**：初始开口分别为最大 12 / 20 mm，规格调节范围为 1–12 / 1–20 mm。超出范围会提示；未计算衍射。[官网规格](https://www.lbtek.com/product/325)
- **10 片装反射镜**：保留采购包装型号，但每次添加仅放置一片。目录不统计现有库存，也不重复累加报价与订单数量。
- 透镜用固定焦距薄透镜模型；波片采用理想延迟；ND 仅模拟透射衰减；光谱滤光片使用阶跃近似。厂商平均值或下限映射为常数时已明确标注。
- BBO 的光学接触窗口额外光程未建模；未给出的切割角等参数保留通用默认值并提示核对。机械外壳长度不当作晶体光学厚度。
- 未收录的口径、透过率、折射率等仍可编辑，并标作通用默认值；默认模型能用于光路布置，不代表完整实测器件。部分 Thorlabs 反射镜补充规格来自官方历史目录，不能据此判断当前在售状态。

## 维护

[lab-records.json](lab-records.json) 为当前内置目录的唯一源数据，[coverage.json](coverage.json) 为分类计数与来源索引。`original-records.json`、`verified-additions.json` 保留此前的公开目录资料，默认构建不加载。

修改已核实记录后，在项目根目录运行：

```powershell
node scripts/build-catalog.cjs
```

脚本离线校验来源、参数、可调范围和重复型号，生成 `dist/catalog-data.js` 和 `catalog/coverage.json`。不读取原始报价、发票或订单文件，也不联网更新。

用户导入的同厂商同型号快照优先于内置数据；手动再次导入已存在型号时会跳过，不覆盖。旧设计保留的其他型号仍可继续使用。目录 JSON 允许仅提供 `documents` 来源，此时 `source` 为空字符串，界面不生成空链接。
